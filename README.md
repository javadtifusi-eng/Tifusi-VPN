# Tifusi VPN (Android)

اپلیکیشن شخصی اندروید برای وصل و قطع کردن سریع VPN سرورهای [Tifusi Panel](https://github.com/javadtifusi-eng/Tifusi-Panel)، بدون رفتن به تنظیمات گوشی سامسونگ.
رابط کاربری دوزبانه فارسی/انگلیسی، با تم تیره نئونی.

> **وضعیت:** کد کامل نوشته شده ولی **هنوز کامپایل و روی گوشی تست نشده** (محیطی که کد در آن نوشته شد SDK اندروید نداشت).
> اولین build ممکن است چند خطای کوچک کامپایل داشته باشد.

---

## ساخت APK

### روش ۱: GitHub Actions (بدون نیاز به Android Studio)
1. پروژه را در یک ریپازیتوری گیت‌هاب push کنید.
2. در تب **Actions**، workflow به اسم **Build APK** خودکار اجرا می‌شود (یا دستی با *Run workflow*).
3. بعد از اتمام، از بخش **Artifacts** فایل `tifusi-vpn-debug` را دانلود کنید؛ داخلش APK هست.

### روش ۲: Android Studio
1. پوشه پروژه را با Android Studio (نسخه Koala یا جدیدتر) باز کنید.
2. صبر کنید Gradle sync تمام شود (Gradle 8.7، JDK 17).
3. `Build > Build App Bundle(s) / APK(s) > Build APK(s)`

### نصب روی سامسونگ
APK را به گوشی منتقل کنید، بازش کنید و اجازه «نصب از منابع ناشناس» را برای برنامه‌ای که با آن باز کردید بدهید.

## پروتکل‌ها

| پروتکل | وصل/قطع داخل اپ | حداقل اندروید | توضیح |
|---|---|---|---|
| **IKEv2/IPsec** | ✅ خودکار | 11 | با API رسمی `VpnManager` + `Ikev2VpnProfile`. روی اندروید ۸ تا ۱۰ به تنظیمات گوشی هدایت می‌شود. |
| **WireGuard** | ✅ خودکار | 8 | با کتابخانه رسمی WireGuard (`GoBackend`). آمار دانلود/آپلود فقط برای این پروتکل نمایش داده می‌شود. |
| **L2TP/IPsec** | ⚠️ نیمه‌خودکار | 8 | اندروید API عمومی ندارد. اپ اطلاعات را نشان می‌دهد (با لمس کپی می‌شود) و صفحه VPN تنظیمات را باز می‌کند. |
| **PPTP** | ⚠️ نیمه‌خودکار | 8 | مثل L2TP. نسخه‌های جدید اندروید PPTP را از تنظیمات حذف کرده‌اند. |

اولین اتصال IKEv2 یا WireGuard یک پنجره تأیید سیستمی نشان می‌دهد؛ این یک‌بار است.

## احراز هویت IKEv2 و گواهی‌ها

سه حالت:

1. **PSK (کلید مشترک)**
2. **نام کاربری/رمز (EAP-MSCHAPv2)**: گواهی CA سرور اختیاری است ولی اگر گواهی سرور self-signed است، الزامی است.
3. **گواهی (RSA/EC)**: گواهی کلاینت + کلید خصوصی + گواهی CA سرور.

### فرمت‌های قابل قبول
- **گواهی CA سرور:** فایل `.crt` / `.cer` / `.pem` (هم PEM هم DER) یا چسباندن متن PEM
- **گواهی کلاینت:** فایل `.p12` / `.pfx` (با رمز)، **یا** گواهی PEM/DER + کلید خصوصی PKCS#8 جداگانه
- اگر فایل `.p12` خودش CA را داشته باشد و CA جداگانه وارد نشود، از همان استفاده می‌شود.

### چک‌هایی که قبل از ذخیره انجام می‌شود
- فایل واقعاً گواهی X.509 است
- **تاریخ انقضا** (منقضی شده / هنوز معتبر نشده، با نمایش تاریخ)
- گواهی CA واقعاً CA است: اگر گواهی خود سرور به‌جای CA انتخاب شود خطا می‌دهد (گواهی self-signed سرور پذیرفته می‌شود)
- رمز `.p12` درست است و فایل کلید خصوصی و گواهی کلاینت دارد
- کلید خصوصی قابل خواندن است (RSA یا EC)
- اگر Remote ID وارد شود، باید با آدرس سرور یکی باشد. API اندروید همیشه آدرس سرور را Remote ID می‌گذارد و راهی برای تنظیم جداگانه‌اش ندارد.
- شناسه محلی (IPsec identifier) برای PSK الزامی است. در حالت یوزر/پسورد پیش‌فرضش نام کاربری است و در حالت گواهی، CN گواهی کلاینت.
- اگر CA سرور وارد نشده، هشدار داده می‌شود و ذخیره نیاز به تأیید دوباره دارد

### مشکلات رایج
| پیام | راه‌حل |
|---|---|
| کلید در قالب PKCS#1 است | `openssl pkcs8 -topk8 -nocrypt -in key.pem -out key8.pem` |
| رمز `.p12` اشتباه است (ولی رمز درست است) | فایل با OpenSSL 3 و رمزنگاری جدید ساخته شده که بعضی نسخه‌های اندروید نمی‌خوانند. دوباره بسازید: `openssl pkcs12 -export -legacy -in client.crt -inkey client.key -certfile ca.crt -out client.p12` |
| سرور اتصال را رد کرد | آدرس سرور در اپ باید دقیقاً همان شناسه‌ی سرور باشد (`leftid` در strongSwan یا SAN گواهی سرور)، چون اندروید آن را Remote ID می‌گذارد. شناسه‌ی محلی هم باید با چیزی که سرور انتظار دارد (`rightid`) بخواند. |
| بعد از ۳۰ ثانیه وصل نشد | پورت‌های UDP 500 و 4500 روی سرور باز باشند. |

در اندروید ۱۳ و بالاتر، شکست مذاکره IKE از سیستم خوانده و نمایش داده می‌شود. در اندروید ۱۱ و ۱۲ فقط بعد از ۳۰ ثانیه خطای timeout نمایش داده می‌شود.

## فرمت بارکد (QR)

اسکن بارکد فقط فرم را پر می‌کند؛ پروفایل همیشه قبل از ذخیره نمایش داده و بررسی می‌شود.

سه فرم پشتیبانی می‌شود:

1. **JSON** (خام یا base64 / base64url)
2. **URI:** ‏`tifusi://import?data=<base64url JSON>`
3. **کانفیگ استاندارد WireGuard** (همان QR اپ رسمی WireGuard)

### فیلدهای JSON

| فیلد | پروتکل | توضیح |
|---|---|---|
| `protocol` | همه | `IKEV2`، `WIREGUARD`، `L2TP`، `PPTP` (الزامی) |
| `server` | همه | آدرس سرور (الزامی) |
| `name`, `country`, `flag` | همه | نام نمایشی، کشور، ایموجی پرچم |
| `auth` | IKEv2 | `psk`، `eap`، `certificate` |
| `remote_id`, `local_id` | IKEv2 | شناسه سرور / شناسه کلاینت |
| `psk` | IKEv2 | کلید مشترک |
| `ca_cert` | IKEv2 | متن PEM گواهی CA سرور |
| `client_cert`, `client_key` | IKEv2 | PEM گواهی کلاینت و کلید PKCS#8 |
| `p12`, `p12_password` | IKEv2 | base64 فایل ‎.p12‎ و رمز آن |
| `username`, `password` | IKEv2 / L2TP / PPTP | |
| `l2tp_psk` (یا `ipsec_psk`) | L2TP | کلید مشترک IPsec |
| `wg_private_key`, `wg_peer_public_key`, `wg_preshared_key` | WireGuard | |
| `wg_address`, `wg_dns`, `wg_port`, `wg_allowed_ips` | WireGuard | |

مثال IKEv2 با PSK:

```json
{
  "protocol": "IKEV2",
  "name": "Germany",
  "server": "de1.example.com",
  "country": "Germany",
  "flag": "🇩🇪",
  "auth": "psk",
  "remote_id": "de1.example.com",
  "psk": "your-shared-secret",
  "username": "",
  "password": ""
}
```

> ظرفیت QR حدود ۲.۵ کیلوبایت است. گواهی CA معمولاً جا می‌شود، ولی فایل `.p12` معمولاً جا نمی‌شود.
> برای احراز هویت با گواهی، بعد از اسکن فایل `.p12` را از داخل فرم وارد کنید.

```
├── vpn/
│   ├── VpnController.kt        # نقطه ورود واحد وصل/قطع برای همه پروتکل‌ها

│   ├── LegacyVpnLauncher.kt    # L2TP/PPTP → تنظیمات اندروید
│   ├── CertificateStore.kt     # خواندن و بررسی گواهی‌ها

│   └── VpnProfile.kt, VpnProtocol.kt

└── ui/                         # Compose: home، servers، profile، services
```

## محدودیت‌های فعلی
- آمار ترافیک فقط برای WireGuard؛ «سرعت» هنوز محاسبه نمی‌شود.
- اطلاعات پروفایل‌ها (شامل رمزها و کلیدها) در DataStore داخلی اپ ذخیره می‌شود و رمزنگاری جداگانه ندارد. پشتیبان‌گیری اندروید برای اپ غیرفعال است.
- آیکون فعلی نسخه ساده‌شده لوگو است؛ برای لوگوی اصلی از `File > New > Image Asset` در Android Studio استفاده کنید.
- فقط یک پروفایل IKEv2 در هر لحظه توسط سیستم نگهداری می‌شود (محدودیت خود اندروید).
